# 第一章 监督学习框架

## 1.1 问题设定

监督学习假设存在一个未知的目标函数 f，它把输入 x 映射到输出 y。我们只能观察到有限个带标签的样本 (x_i, y_i)，目标是学到一个假设 h，使 h 在没见过的输入上也接近 f。训练集、验证集和测试集的划分，本质上是在模拟“见过”和“没见过”两种情况。

如果假设空间太小，模型无法表达真实规律，这叫欠拟合；如果假设空间过大而数据有限，模型可能把训练集的噪声也记住，这叫过拟合。学习算法的核心任务不是把训练误差压到最低，而是在偏差与方差之间取得平衡。

## 1.2 损失函数与经验风险

损失函数衡量单个预测与真实标签的差距。回归常用均方误差，分类常用交叉熵。经验风险是训练样本上损失的平均值，学习过程通常写成最小化经验风险加正则项。需要注意，经验风险最小并不等于真实风险最小；训练集上的漂亮数字可能只是记忆，而不是泛化。

选择损失函数时要和任务目标一致。例如类别极不平衡时，准确率会被多数类主导，改用 F1 或代价敏感损失更合理。

# 第二章 梯度下降与优化

## 2.1 批量梯度下降

梯度下降是一阶优化方法：沿着损失函数负梯度方向更新参数，使损失逐步下降。批量梯度下降每次用全部训练样本计算梯度，方向稳定，但单步成本高，数据量大时一次更新就要扫完整份数据。

参数更新公式为 θ ← θ − η ∇L(θ)，其中 η 是学习率。学习率过大会在极小值附近来回震荡甚至发散，学习率过小则收敛缓慢。

## 2.2 随机梯度下降与小批量

随机梯度下降每次只用一个样本估计梯度，单步便宜但噪声大，更新路径抖动明显。小批量梯度下降取两者折中：每次用一小批样本，既利用矩阵运算的并行性，又保留一定的随机性。批大小会影响力更新的噪声尺度和泛化表现。

在实践中，小批量随机梯度下降是深度学习的默认选择。训练前通常要打乱数据，避免样本顺序带来系统性偏差。

## 2.3 学习率与动量

动量法把历史梯度累积成速度，相当于给参数更新加上惯性，可以穿过狭窄的峡谷并抑制震荡。Adam 进一步结合一阶矩和二阶矩的自适应估计，对每个参数使用不同的有效学习率。

学习率调度同样重要：前期用较大学习率快速下降，后期逐步衰减以精细收敛。余弦退火、阶梯衰减和 warmup 都是常见策略。判断学习率是否合适，可以观察训练损失曲线：震荡说明偏大，几乎不降说明偏小。

# 第三章 过拟合与正则化

## 3.1 过拟合的表现

过拟合的典型信号是训练误差持续下降，而验证误差先降后升，两者差距扩大。模型在训练集上几乎完美，却在新样本上表现很差。数据太少、特征太多、模型容量过大、训练轮数过多，都会加剧过拟合。

应对过拟合的手段包括增加数据、数据增强、简化模型、早停、正则化和集成。早停的本质是在验证误差开始上升时停止训练，相当于一种隐式的容量控制。

## 3.2 L1 与 L2 正则化

L2 正则化在损失中加入权重平方和的惩罚，倾向于让权重整体变小但很少恰好为零，因此也叫权重衰减。L1 正则化惩罚权重绝对值之和，容易把部分权重压到零，产生稀疏解，可用于特征选择。

正则化系数控制惩罚强度：系数太大导致欠拟合，系数太小则约束不足。标准化特征后再做正则化很重要，否则量纲大的特征会被过度惩罚。

## 3.3 Dropout 与数据增强

Dropout 在训练时随机失活一部分神经元，迫使网络不依赖某几个特定单元，相当于训练了许多共享参数的子网络。推理阶段通常关闭 Dropout，并对输出做相应缩放。数据增强通过旋转、裁剪、加噪等方式扩充有效样本，是计算机视觉中对抗过拟合最有效的手段之一。

# 第四章 偏差-方差权衡

偏差描述模型预测的期望与真实值之间的系统性差距，方差描述不同训练集上模型预测的波动。高偏差通常意味着模型过于简单，表现为欠拟合；高方差意味着模型对训练数据过于敏感，表现为过拟合。

增加模型复杂度通常会降低偏差、提高方差；增加训练数据通常会降低方差而对偏差帮助有限。集成方法中的 Bagging 主要通过降低方差起作用，Boosting 则逐步降低偏差。理解这一点有助于判断该换模型、加数据还是改特征。

# 第五章 评估方法

## 5.1 准确率、精确率与召回率

准确率是预测正确的比例，在类别均衡时直观，但在极不平衡数据上会误导。精确率衡量预测为正的样本中有多少真的是正例，召回率衡量真实正例中有多少被找出来。二者往往此消彼长，需要根据业务代价选择阈值。

例如疾病筛查更看重召回率，宁可多报也不能漏诊；垃圾邮件拦截更看重精确率，避免把正常邮件误杀。

## 5.2 交叉验证

K 折交叉验证把数据分成 K 份，轮流用其中一份做验证、其余做训练，最后平均各折结果。它比单次划分更稳定，尤其在数据量小时能减少评估的偶然性。分层 K 折会保持每折的类别比例，适合分类任务。

时间序列不能随机打乱做交叉验证，必须按时间切分，否则会用未来信息预测过去，导致评估过于乐观。

## 5.3 ROC-AUC

ROC 曲线以假正率为横轴、真正率为纵轴，AUC 是曲线下面积，可理解为随机取一个正例和一个负例、模型把正例排在负例前面的概率。AUC 不依赖具体阈值，适合比较模型排序能力，但在极端不平衡时仍可能偏乐观，此时 PR 曲线更敏感。
