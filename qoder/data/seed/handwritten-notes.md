# 2026-10-12 复盘：梯度下降

今天做题又把学习率和步长搞混了。学习率 η 是超参数，决定每一步走多远；步长是 η 乘上梯度后的实际位移。之前我一直以为“步长”是固定的，其实它随梯度大小变化，靠近极小值时梯度变小，步子也会自动变小。

还有一个容易错的点：批量梯度下降和随机梯度下降的区别不只是“快慢”。批量法用全量数据，梯度方向确定，损失曲线单调下降；随机法每次只用一个样本，损失会抖动，但抖动反而可能帮助跳出不好的区域。小批量是折中。

我自己总结的判断方法：如果训练损失一直震荡不降，先怀疑学习率太大；如果损失几乎不动，先怀疑学习率太小或者梯度消失。不要一上来就换模型。

# 2026-10-18 复盘：特征值与 PCA

特征向量是“方向不变的向量”，这句话我抄了很多遍，但今天才真正理解。Av=λv 的意思是：变换之后方向没变，只改变了长度，λ 就是缩放倍数。如果 λ 是负数，方向反了；如果 λ 是复数，说明有旋转。

PCA 的步骤我总是记不全。正确顺序是：先中心化，再求协方差矩阵，然后做特征分解，按特征值从大到小排序，取前 k 个特征向量作为投影方向。特征值就是对应方向上的方差。忘记中心化是我上次作业扣分的原因——不中心化的话，第一主成分会指向均值方向，而不是方差最大的方向。

我还混淆过特征值分解和 SVD。特征分解要求方阵且最好可对角化；SVD 对任意矩阵都成立。PCA 两种都能做，但数据矩阵不是方阵时，直接用 SVD 更省事。

# 2026-10-25 复盘：正则化与过拟合

L1 和 L2 的区别我用一句话记：L1 会把不重要的权重直接变成 0，所以能做特征选择；L2 只是把权重整体压小，很少变成 0。之前我以为 L2 也能稀疏，这是错的。

正则化系数 λ 不是越大越好。λ 太大，模型被压得太死，训练集都拟合不好，变成欠拟合；λ 太小，约束不够，过拟合依旧。调 λ 要看验证集，不要看测试集。

还有个细节：做正则化之前要标准化特征。否则量纲大的特征即使真实权重不大，也会因为数值大而被惩罚得更狠，结果不公平。

# 错题摘录：偏差与数据切分

错题一：把“偏差”当成“误差”。偏差是模型预测的期望与真实值的系统性差距，误差还包含方差和噪声。高偏差对应欠拟合，高方差对应过拟合。

错题二：交叉验证时打乱了时间序列，用未来数据预测过去。时间序列必须按时间切分，否则评估会过于乐观。
